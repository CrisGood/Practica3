# Practica3

Este repositorio contiene el backend de conexión a PostgreSQL:

- `server.js`
- `package.json`
- `package-lock.json`

El servidor expone las rutas API de registro, login y obtención de usuarios.

Para ejecutar:

1. Instala dependencias con `npm install`.
2. Ajusta los datos de conexión a PostgreSQL.
3. Inicia con `node server.js`.
